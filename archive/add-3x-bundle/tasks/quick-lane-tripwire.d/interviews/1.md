# interview 1 — quick-lane-tripwire

## A1 [who]
- asked: the agent or human who made the change, as intake.md's route line already says — the engine reads the sha, not the author
- if wrong: cost if wrong: a quick line filed by a reviewer for someone else's commit is inspected the same way, which is the point
- answered: confirm

## A2 [which]
- asked: OPEN and FROZEN Tasks only — a done task's scope is history, an unfrozen task's scope is a draft nobody sealed
- if wrong: cost if wrong: a quick commit into a task's scope the day before its freeze is not refused; the freeze's own receipt freshness catches the moved blob
- answered: confirm

## A3 [when]
- asked: both — `add locate` before (skill) and `learn` after (engine) — because the engine sees nothing until the bundle is written, and a refusal after the commit still names the task to create before the branch merges
- if wrong: cost if wrong: a refused commit stays in the branch history; the refusal names the fix, and the direct lane's commit is the author's to amend
- answered: confirm

## A4 [absent]
- asked: no sensitive floor — only open scopes are matched — and an `index.md` with no key the same
- if wrong: cost if wrong: a bundle that never declared sensitive paths gets no sensitivity tripwire, which is what it declared
- answered: confirm

## A5 [order]
- asked: the sensitive floor first (it is unstrikeable and outranks a scope), then the first open task in cid order
- if wrong: cost if wrong: a CI diff churns
- answered: confirm

## A6 [experience]
- asked: the refusal to name the path, the reason (the pattern or the task) and the exact `add new Task` line with the path as `--scope`

## M1 [source]
- asked: `learn` whose lesson text starts `quick:` and whose `--evidence` is a git object name resolving to a commit (`rev-parse --verify -q <sha>^{commit}`) reads that commit's changed paths (`diff-tree --no-commit-id --name-only -r`, read-only) and refuses R:QUICKSIZEUP when any path matches an `index.md` `sensitive_paths:` pattern (naming the path and `floor human`) or lies under an OPEN Task's `scope:` (naming the path and the task cid); the refusal names the fix — `add new Task <slug> --scope <path>` — and writes no lesson
- answered: confirm

## M2 [source]
- asked: the match is the engine's own: `_paths_touch` for sensitive patterns (A17's matcher) and scope containment as `scope_digest` reads a scope entry; OPEN means a Task whose status is not `done`, `dropped` or `archived` and that carries a freeze stamp (an unfrozen scope has frozen nothing)
- answered: confirm

## M3 [source]
- asked: a `quick:` lesson whose evidence is not a commit (a receipt cid, a path, prose), or whose sha git cannot resolve, or in a tree that is not a repo, is recorded exactly as today — the tripwire reads git and never blocks the lane on git's absence; a lesson not opening `quick:` is never inspected
- answered: confirm

## M4 [source]
- asked: the verb calls git READ-ONLY (`rev-parse`, `diff-tree`) — never `commit`, `checkout`, `reset` or any command that moves the tree (R:OUTWARD)
- answered: confirm
