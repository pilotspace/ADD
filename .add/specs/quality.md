## Decisions that bind
- The SKILL.md sha256 prose pin is still scattered across two files — the same class as the budget scatter, carried into 3.7 knowingly rather than folded as done. (from: /specs/quality.md#Q30)
- A pinned number lives in one module and is asserted by one named guard; a shared-constant guard flags the re-DECLARATION as well as the assertion, because a module-level constant asserts with no literal to find. (from: /specs/quality.md#Q29)
- A scope guard names the commit range its claim is about, or asserts the premise that must still hold. A working-tree diff guards neither, and `git commit` alone satisfies it — a guard that fires on unrelated work is dismissed until it is worth less than no guard. (from: /specs/quality.md#Q28)
- A falsy return that is not None makes every `is not None` assertion against it vacuously green — normalising the shape is a correctness fix, not a style one. (from: /specs/quality.md#Q27)
- A scope guard names the commit range it guards, never the working tree: a guard pinned to an uncommitted diff reds every unrelated build in progress and passes the moment anything is committed. (from: /specs/quality.md#Q24)
- A batch of edits planned against a snapshot is re-verified against the live file immediately before it runs, and each call states the ids it expects to touch; a command that reports only a count cannot tell you what it swept. (from: /specs/quality.md#Q26)
- A capability a doc promises, a command it shows, or a reason it gives for a rule is bound to behaviour by an executed check; prose no check binds is a claim, not a constraint. (from: /specs/quality.md#Q6)
- Every check is audited by injecting the defect it names before it is cited: a failure-code assertion carries a success floor, an absence assertion asserts existence first, a fixture asserts its own postcondition, and a pin reads nothing from the source it pins. (from: /specs/quality.md#Q17)
- No check reads a gitignored path; an exists-skip carries a floor sized by the claim it attests, and the floor is proven by running the suite with every gitignored path hidden. (from: /specs/quality.md#Q22, #Q21)
- A check cited by covers: is one plain test function named bare, never parametrized and never a module, with its cases looped from a module constant so the table stays readable. (from: /specs/quality.md#Q25, #Q16, #Q9)
